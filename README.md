# Sistema-de-Adquisicion-de-Datos-de-Calidad-del-Aire-con-ESP32-y-Sensor-MQ-135
Este artículo describe el diseño, implementación y validación de un sistema embebido para la adquisición y visualización en tiempo real de datos de calidad del aire, empleando el microcontrolador ESP32 (DOIT DevKit V1, revisión de silicio v3.1) y el sensor electroquímico MQ-135
